## Ambiente Virtual

### Ambiente Virtual

```bash
mkdir myproject
cd myproject
python3 -m venv .venv
```

### Ativação Ambiente Virtual

```bash
# Linux / macOS
. .venv/bin/activate

# Windows (CMD)
.venv\Scripts\activate.bat

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```
